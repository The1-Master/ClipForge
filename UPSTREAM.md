# ClipForge source provenance

ClipForge is a local desktop fork of [CS DemoDesk](https://github.com/noih/cs-demodesk) by NOIH, pinned to `a85e85130d80d72a3415ee8ee01ee94626c43e5f` (v1.0.29, 2026-10-12).

ClipForge is an original working title for this fork. No trademark registration or official affiliation is claimed. The original application name is retained only in source provenance, historical documentation and dependency attribution.

The upstream AGPL-3.0-only license and copyright are retained in LICENSE. The vendored demoparser retains its MIT license in vendor/demoparser/LICENSE. FidelityFX, Microsoft Detours and other dependencies retain their notices. HLAE, FFmpeg and Source 2 Viewer are separately licensed tools. See the About dialog and [beta verification notes](docs/BETA-0.3.0.md) for evidence and known limits.

Changes add workspace confinement, distinct branding, event-centered discovery, local feedback, voluntary contributions and gated learning workflows. Development files belong under J:/CS2ClipStudio; public packages use their own adjacent workspace. No upstream binary updater is active. Corresponding source is published at https://github.com/The1-Master/ClipForge. Binary releases include the license and matching modified source, retaining dependency notices.
